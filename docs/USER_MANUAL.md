# Panduan Pengguna TripReady
1. **Beranda** — baca ringkasan lalu tekan **Mulai Rencanakan**.
2. **Lokasi awal** (opsional) — ketik alamat, tekan **📍 Lokasi saya**, atau **🗺️ pilih titik di peta**. Tanpa lokasi awal, estimasi rute tidak ditampilkan.
3. **Tujuan** — ketik nama tempat lalu pilih dari daftar saran.
4. **Aktivitas & transportasi** — pilih sesuai rencana. Untuk wisata, isi juga lama menginap.
5. **Tanggal & jam berangkat** — maksimal 16 hari ke depan.
6. Tekan **Lihat Rekomendasi**. Hasil berisi verdict, cuaca, jam buka, estimasi perjalanan, dan Plan A/B/C.
7. **Peta & Rute**, **Cuaca per Jam**, dan **Checklist** (khusus wisata) tersedia di menu kiri. Tombol **ⓘ Asal angka** menjelaskan sumber setiap angka.
8. **Pengingat** — pilih waktu, tekan **Aktifkan notifikasi**, lalu izinkan saat ditanya. Notifikasi akan muncul walau web ditutup (bisa telat sekitar 2 menit).

**Masalah umum:** "Tempat tidak ditemukan" → tambahkan nama kota. "Lokasi tidak bisa dibaca" → izinkan lokasi di peramban atau pilih titik manual. Hasil lambat → API publik sedang sibuk, coba lagi.
